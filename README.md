# Scheme Finder India

A personalized platform to discover Indian central government schemes you are eligible for.

## Tech Stack
- **Next.js 14** (App Router)
- **Tailwind CSS**
- **TypeScript**
- **Lucide React** (Icons)

## Features
- **Smart Filtering:** Matches schemes based on age, occupation, and income.
- **Mobile First:** Fully responsive design for all devices.
- **Fast UX:** 1s simulated loading state for smooth transitions.
- **Production Ready:** Clean, modular code structure.

## Getting Started

First, navigate into the project directory:

```bash
cd scheme-finder-india
```

Install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
